# 《开心弹珠机》 (Happy Pachinko Arcade) - V3.0 正式版

基于实物街机台与真实商用游艺规则 1:1 深度还原制作的**拟真微缩复古玩具风物理弹珠机网页游戏 (HTML5 / Canvas / Web Audio)**。

---

## 一、V3.0 核心改进与机器规则说明

### 1. 免费加珠（密码验证管理）
- 点击顶部的【免费加珠】按钮后
- 弹出密码验证窗口，输入当前管理密码（默认 `ma123456`，可在【设置】中修改）。
- 验证成功后弹出“设定添加珠子数量”，提供用户名、数字输入框及快捷按钮（+50、+100、+500、+1000），点击确定即可直接像指定用户充入总珠子余额。

### 2. 真实街机核心对局规则
- **投珠开局（5 ~ 99 颗）**：
  - 点击或长按【投珠】按钮投入 5 ~ 99 颗小弹珠。
  - 投入达到 5 颗以上后，点击【开始】按钮，机台启动**摇号轮播抽取倍率**（2× / 4× / 6× / 8× / 10×）。
- **12 落点亮灯分布**：
  - 倍率决定底部 12 个落点孔洞中的随机亮灯数量：
    - **2× 倍率**：随机点亮 **4 个** 灯格；
    - **4× 倍率**：随机点亮 **3 个** 灯格；
    - **6× 倍率**：随机点亮 **2 个** 灯格；
    - **8× / 10× 倍率**：随机点亮 **1 个** 灯格。
  - 选中的亮灯格具备高亮红色光圈呼吸闪烁与立体发光效果，未亮灯格保持暗黑凹坑。
- **开局前可追加投珠**：
  - 玩家看到抽中的倍率与亮灯位置后，**在拉杆发射前依然可以继续按【投珠】追加弹珠（上限 99 颗）**！
- **发射与中奖判定**：
  - 向下拉动右下角红色猫爪拉杆蓄力发射，弹珠冲顶滑过天花板落入钉阵。
  - **落入亮灯格（中奖）**：
    - **中奖返珠** = `倍率 × 投珠数`（例如投 20 颗，倍率 4×，赢得 80 颗珠子）。
    - **积分卡奖励** = `min(floor(返珠数 / T), J)`。
      - 其中 $T$ 为每多少返珠获得一张积分卡，$J$ 为单次出积分卡上限。
      - 可在【设置】面板自定义机台的 $T$ 与 $J$ 参数（默认 $T=10$, $J=10$）。
    - 触发爆奖音效、屏幕震动、成串弹珠喷涌滚落进底部猫脸托盘。
  - **落入未亮灯格（未中奖）**：
    - **珠子全损**，返还 0 颗珠子，触发叹气音效。
  - 结算完成后对局自动复位，进入下一轮投珠。

### 3. 便捷投珠操作
- 单击【投珠】：单次投珠 +1。
- **长按【投珠】**：手指或鼠标按住不放时，触发每秒约 15 颗的极速连续自动投珠，松手立即停止，达到 99 颗或珠子不足时自动停止。

### 4. 纯净默认初值
- 游戏初次载入或重置后，**所有数据默认为 0**：
  - 总积分：0
  - 总珠子：0
  - 奖励珠子：0
  - 奖励积分：0
- 玩家启动游戏后，先点击【免费加珠】（默认密码 `ma123456`，可在设置中修改）存入弹珠即可畅玩！

### 5. 多机器设置范围
- 【设置】中的音效、参数 T、参数 J、倍率概率和管理密码属于全部机器配置，保存后会同步到同一站点中已打开的机器页面。
- 管理密码明文保存在 `global-config.json` 的 `password` 字段中（默认 `ma123456`），进入设置后可填写新密码并保存。
- 弹珠数量和积分数量只属于当前机器，不会覆盖其他机器的数据。
- 【重置当前机器数据】只会清空当前机器的弹珠、积分和当前对局，不会重置全部机器配置。

## 二、文件目录结构

```text
happy_pinball_game/
├── index.html        # 游戏主页面 (12落点机台布局、倍率指示与管理充值弹窗)
├── style.css         # 像素级还原拟真玩具街机视觉、3D猫爪、LED数码管与动效
├── physics.js        # 自研 2.5D 高精度物理引擎 (12落点光圈、平滑冲顶天花板、防穿钉CCD)
├── audio.js          # 原生 Web Audio API 合成音效 (投珠、轮播Tick、锁定Ding、中奖琶音)
├── game.js           # 完整规则状态机 (投珠/倍率抽选/追加/中奖判定/密码管理)
├── server.js         # 本地共享服务 (全部机器配置同步)
├── global-config.json # 全部机器配置
└── README.md         # 详细开发与规则说明文档
```

## 三、运行方式

需要多机器共享设置时，在安装了 Node.js 的主机上运行命令或脚本：

```bash
node server.js
```

``` 
Linux: start.sh
MacOS: start.command
```

当前主机访问 `http://localhost:8066`，其他机器访问 `http://<主机局域网 IP>:8066`。音效、T、J、倍率概率和管理密码会保存到服务端并同步到全部机器；每台机器的弹珠和积分仍保存在各自浏览器中。

直接双击 `index.html` 仍可离线运行，但这种方式只能同步同一浏览器中打开的页面，无法跨设备共享配置。
